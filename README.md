# THINKナゴヤ WEBサイトデータ

## 構成
- `index.html`：トップページ本体
- `assets/css/style.css`：デザインCSS
- `assets/js/main.js`：メニュー・表示アニメーション
- `assets/img/`：SVG素材・参考デザイン画像
- `assets/docs/`：提言骨子、概要、メンバー一覧PDF

## 公開方法
このフォルダ一式をそのままサーバーにアップロードしてください。
Cloudflare Pages / Netlify / Xserver / さくらサーバー等の静的ホスティングで利用できます。

## 修正ポイント
- お問い合わせメール：`index.html` 内の `mailto:info@example.com` を正式なアドレスへ変更してください。
- SNSリンク：フッターの `#` を正式URLへ変更してください。
- 活動レポート：現時点ではダミー記事です。公開時に実際の記事内容へ差し替えてください。
